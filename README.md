# MLOps_Learning · AC215 study workspace

My companion repo for **AC215 / E115 · MLOps & LLMOps: Production AI Systems** (Harvard, Fall 2026,
Pavlos Protopapas). The course teaches through hands-on tutorials, one or more per lecture, each
in a GitHub repo of [dlops-io](https://github.com/dlops-io). This repo ties them together:

- **a course map**: lecture → tutorials → repo (and README section) → study guide → video;
- **one command to get all the tutorial code**, laid out the same way on every machine;
- **a study guide per lecture**: every step with the exact command, the files involved as
  `path:line`, the concepts behind it, the gotchas, and exercises with answers;
- **a 3Blue1Brown-style explainer video per lecture**, made in my
  [Explainer_Videos](https://github.com/JunyiZhou-Conny/Explainer_Videos) repo, that walks through
  the tutorial command by command so I can follow along with my own clone open (English narration;
  English, Chinese and bilingual subtitles);
- **my notes** (`notes/`).

> 中文简介：这是我上 AC215 的学习仓库。每一讲对应一个（或几个）dlops-io 的 tutorial repo；这里有课程
> 地图、一键 clone 全部 tutorial 的脚本、每讲的学习指南（逐条命令 + `path:line` + 原理 + 常见报错 +
> 练习），以及 Explainer_Videos 里对应的讲解视频（英文旁白，配中文字幕和中英双语字幕）。用法：
> 打开视频，旁边开着自己的 clone，一边看一边做。

## Quick start

```bash
# 1. this repo is the AC215 folder (e.g. ~/Desktop/AC215)
git clone https://github.com/JunyiZhou-Conny/MLOps_Learning.git ~/Desktop/AC215
cd ~/Desktop/AC215

# 2. get every tutorial repo into tutorials/ (needs git and uv, both from Tutorial 0)
uv run tools/sync_tutorials.py              # clone what's missing, fast-forward the rest
uv run tools/sync_tutorials.py --only 5     # just lecture 5's repos
uv run tools/sync_tutorials.py --status     # what's cloned, on which commit, dirty or not

# 3. to match a video frame for frame, check out the commits it was made from
uv run tools/sync_tutorials.py --pinned     # ...and --latest to go back to main
```

Already have clones somewhere else (say an older `~/Desktop/AC215`)? Move them into `tutorials/`,
or point the script at them: `AC215_TUTORIALS=~/somewhere uv run tools/sync_tutorials.py --status`.
The script never touches a repo with uncommitted changes, so your edits in a tutorial are safe.

## How to study one lecture

1. **Before class (5 min):** read sections 1–3 of the lecture's guide: what you build, what it
   costs, the concepts.
2. **Watch the video with your clone open.** The top-left corner of the video always shows where
   you are in the tutorial README (*README › section › step k of N*), and every code panel shows its
   `path · lines a–b`, so you can pause and find the same lines in your editor.
3. **Do the tutorial yourself**, using the guide's step list as the checklist. When something fails,
   look in the guide's *Gotchas* section (6) first.
4. **Exercises** (guide section 8) without re-watching; re-watch only the chapter you got wrong.
5. **Notes** in `notes/LNN.md`, in your own words (template in [notes/README.md](notes/README.md)).
6. **Shut down what you started** (VMs, buckets, clusters). Every guide lists the billable
   resources it creates.

## Layout

```
course/lectures.yaml        single source of truth: lectures, tutorials, repos (+ pinned commits), guides, videos
tools/sync_tutorials.py     clone / update / pin every tutorial repo into tutorials/
tools/course_map.py         regenerate the course map above from lectures.yaml (--check in CI)
guides/LNN-<topic>.md       one study guide per lecture
notes/                      my own notes, one file per lecture
tutorials/                  the cloned tutorial repos (gitignored: each is its own git repo)
```
